1\. Título del Proyecto

Proyecto de Desarrollo de un Motor Inteligente de Generación Automática de Contratos

2\. Tecnologías / Herramientas / Metodologías Aplicables

Python, FastAPI, React.js, Azure OpenAI Service, Azure AI Document Intelligence,

PostgreSQL, Docker, GitHub Actions, LangChain, Microsoft Entra ID y Scrum.

3\. Delimitación del Proyecto

El proyecto desarrollará un motor inteligente capaz de generar automáticamente contratos

empresariales a partir de plantillas parametrizadas, reglas jurídicas y datos estructurados.

Incorporará inteligencia artificial para redactar cláusulas, validar consistencia documental y

reducir tiempos de elaboración, manteniendo trazabilidad y control de versiones.

4\. Objetivos

Objetivo General:

Desarrollar un motor inteligente para la generación automática de contratos empresariales.

Objetivos Específicos:

• Analizar los procesos actuales de elaboración contractual.

• Diseñar la arquitectura tecnológica.

• Implementar generación automática y validación documental.

• Validar la calidad de los documentos generados.

• Elaborar documentación técnica y plan de soporte.

5\. Justificación

Impacto en la Industria: Reduce tiempos de elaboración y estandariza la documentación

contractual.

Valor para PluriOne: Amplía el portafolio LegalTech con inteligencia artificial aplicada a

documentos jurídicos.

Desarrollo del Alumno: Fortalece competencias en IA generativa, automatización

documental y arquitectura empresarial.
